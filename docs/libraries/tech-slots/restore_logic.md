Upon death, saved modifiers will be restored onto to the body slot item. Additionally, the `#smithed.tech_slots:player/restore_modifiers` function tag will be run after this default restore process. Data packs can add functions to this function tag to run after the library restores saved modifications to the body slot. This can be useful to for packs that use custom data on the body slot as a placeholder/signifier and needs to be reinitialized upon respawning. E.g. a player loses a heart every death.
